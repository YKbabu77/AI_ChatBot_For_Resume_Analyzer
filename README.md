## 📌 About the Project

**AI Resume Analyzer Chatbot** is a Generative AI-powered Telegram bot designed to help candidates evaluate their resumes against a specific Job Description.

The chatbot allows a user to upload **one or multiple resumes**, provide a **Job Description**, and receive an **individual AI-generated analysis for each resume**.

For every resume, the chatbot provides:

- 📊 ATS Score
- ✅ Matching Skills
- ❌ Missing Skills
- 📚 Learning Suggestions
- 🔗 Course Links

This makes it easier for candidates to understand how well their resume matches a particular job and what skills they should improve.
